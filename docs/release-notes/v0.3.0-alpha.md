# GolfSG v0.3.0-alpha

Build 3 improves on-course input and adds optional local usage summaries.

## Highlights

- Collapsible input sections with category scores and scrolling to the selected section.
- Approach and around-green distance controls with ±1 m/±5 m buttons and an exact-input popup that selects the existing number on Android. Green finish distances retain decimal precision.
- Configured around-green starts collapse to a compact, editable lie-and-distance summary.
- Confirming a completed finish distance opens the next visible pane after a 350 ms pause with animated scrolling.
- New holes open the first visible pane and scroll to the top.
- Done releases focus and closes the distance popup; tapping outside inline fields dismisses the keyboard.
- Approach and finish distances up to 300 m.
- Around Green disappears when the approach finishes on Green or in the hole.
- Running scores for configured categories, 9/18-hole shortcuts, and clearer tracking switches.
- Beta gating for Approach and Around Green configuration and mandatory tracking selection.
- Fixed the Kortklippet 41 m approach-finish crash and duplicate final-hole actions.
- Optional local usage summaries, disabled by default, with export/deletion in Settings. No automatic uploads. Unexpected session endings are not a confirmed crash rate.

## Validation

Android Debug builds passed without warnings or errors, and the updated app was installed and launched on a Samsung SM-S921B. Application and test projects compile with the installed .NET 10.0.401 SDK; Windows application control blocks local test execution. The pinned SDK 10.0.302 is unavailable locally. CI must verify tests and Release packaging with the pinned SDK. Physical-device interaction checks, diagnostics export/deletion, upgrade behavior, and reference-data redistribution approval remain outstanding release checks. This alpha does not constitute Apple or Windows store acceptance.
