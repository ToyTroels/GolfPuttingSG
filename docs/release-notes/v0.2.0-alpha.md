# GolfSG v0.2.0-alpha

This alpha focuses on distribution hardening and critical workflow reliability.

## Highlights

- Fixed immediate round setup with approach and around-the-green tracking, backed by a regression test.
- Fixed the default History view so rounds, games, and benchmarks are all visible.
- Added stable accessibility and UI-automation identifiers to critical journeys.
- Added an in-app privacy statement and aligned Android and Apple privacy configuration.
- Reframed strokes-gained tables as general project-maintained reference data and documented the provenance gate.
- Added locked dependency graphs for platform-neutral projects, a pinned .NET SDK, cross-platform CI, Android AAB/APK release validation, and Windows MSIX packaging.

## Before distributing

This remains a prerelease. The release owner must complete the external signing, store metadata, reference-data rights/provenance, and physical-device checks in `docs/RELEASE_CHECKLIST.md` before public distribution.
