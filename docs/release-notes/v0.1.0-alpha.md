# GolfSG v0.1.0-alpha

> Release-note draft. Publish this text with the `v0.1.0-alpha` GitHub Release after the release build and supported-device smoke checks are complete.

GolfSG is an offline-first putting analysis app that records practice and round performance and compares it with a strokes-gained reference baseline.

## Highlights

- Record putting performance hole by hole.
- Review strokes gained for individual holes and complete rounds.
- Configure shorter rounds and finish a round before all configured holes are complete.
- Use guided entry and quick actions for faster mobile input.
- Run putting games, distribution benchmarks, and ladder benchmarks.
- Review, filter, sort, edit, import, and export local history.
- Recover history from a backup when the primary local file is damaged.
- Use the same testable scoring and workflow layers across supported MAUI platforms.

## Important alpha limitations

- This release is intended for evaluation and feedback, not production distribution.
- The core experience is putting; approach and around-the-green tracking remain experimental.
- Distance-unit support is still being completed across the application.
- Data is local to the device. There is no account, cloud synchronization, or multi-device history.
- The putting reference table needs fuller public source and provenance documentation.
- UI automation and visual regression coverage are not yet complete.

Please report reproducible bugs with the platform, app version, steps to reproduce, expected behavior, and actual behavior. Include whether the issue affects an active round, a saved round, or a practice session.
