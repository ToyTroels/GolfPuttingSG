# Course practice rounds (beta)

Enable beta features in Settings, then open **Banerunde på billede · Beta** on the start screen. The menu offers **Spil bane** to choose a saved course and **Opsæt ny bane** to create one. An unfinished round can be resumed, finished early with its recorded results saved, or explicitly discarded from the menu. Each position has a configured number of independent attempts from the same start towards the same target; this is not full golf-hole play until holed.

## Set up a round

1. Choose **Opsæt ny bane** in the menu, enter a course name and press **Fortsæt**. Setup opens directly on the picture, ready to tap the first starting point. The course name appears in the page title and can be changed near **Gem bane**; the beta explanation is also below the shot editor. **Annuller** returns without creating a course. The same name-first flow applies when creating a course from the empty saved-course list. To adjust an existing course, choose **Spil bane**, then open **☰** at the top right of its card and choose **Rediger bane**. New courses use the bundled facility picture, which is available offline. Users cannot select or upload custom course pictures.
2. Open **Hjælp og målestok** below the picture to see placement guidance and the current scale. Calibrate the picture: press **Kalibrer målestok**, place two points with a known distance, press the button again, and enter that distance in metres. Help is collapsed initially to keep the shot fields closer to the picture. The supplied picture starts with an approximate scale based on the user's roughly 110 m reference, not verified map accuracy.
3. Choose **Start**, tap the starting position, then tap the target. A compact summary below the picture shows the whole-metre distance, labelled **Estimeret afstand** or **Målt afstand** when a measured override is used. It updates while dragging and when selecting a saved shot, and disappears for an incomplete shot or calibration. Drag either marker to adjust it, or drag the connecting line to move both positions together. Green marks the start and orange marks the target. Zoom can help with placement.
4. Tap a starting lie under **Hvor ligger bolden ved start?** below the picture. The visible buttons include Tee, Fairway, Rough, Bunker, Kortklippet, Green and Problemlie; the selected option is highlighted. Set **Antal slag** to a whole number from 1 to 100 (default 1), then choose the SG category. For example, 5 means playing five balls from that same position, each with its own outcome and SG. A course supports up to 100 positions and 1,000 attempts in total. Green starts use Putting; tee shots use Approach. Choose Around Green for chips and greenside bunker shots; category is explicit because distance to the green edge cannot be inferred from a picture.
5. Optionally enter a measured shot distance to override the image estimate. The optional name field suggests a name using the shot number, starting lie and distance, such as **Slag 2 · Bunker · 25 m**. Leave it empty to use the suggestion or type your own name. Press **Gem og næste slag** in the fixed bottom bar, outside the picture and scrolling form. This single action saves or updates the shot, clears the editor, dismisses the keyboard and returns to the picture, ready for the next starting point. Invalid input keeps the pending shot and its positions intact so it can be corrected; a missing starting lie brings the choices into view. Errors appear beside the button. Saved shots remain numbered on the picture: drag a marker to adjust an endpoint, or drag its line to move the whole shot. Distance updates while dragging. Moving an endpoint clears an old measured-distance override; moving the whole shot preserves it. Save the course to keep these changes. Select a shot in the list to change its name, lie, category or measured distance; **Gem og næste slag** updates that shot in its original position in the list.
6. Press **Gem bane** to save the layout and return. If an unfinished shot remains after at least one saved shot, you can explicitly discard that draft and save the existing layout, or choose **Tilbage** to keep editing; no shot is silently discarded. Finish calibration before saving. Choose **Spil bane** in the menu, then tap the saved course's card to preview its picture and all planned shots, including distances, starting lies, categories and attempt counts. Choose **Start runde** in the fixed bottom bar when ready. Opening the preview does not create a round. Courses can be previewed during an active round, but starting another remains disabled until the active round is finished or discarded. Courses can be reused. Starting a round freezes the layout, attempt counts, lie, distance overrides and calibration for that session. Existing saved courses without an attempt count retain one attempt per position.

Swipe on empty picture space to scroll down to the shot details. A tap places the selected start or target point only when released; a swipe does not create or move a point. Drags beginning on a marker or connecting line still edit that shot. The fixed **Gem og næste slag** button remains available while scrolling.

Use **Aktuelt slag / Alle slag** above the picture to switch between the current shot and the complete layout. **Aktuelt slag** is selected by default. Hidden saved shots cannot be selected or dragged on the picture; they remain available in the planned-shot list for editing. The toggle preserves the current shot, saved layout and shot numbers, and keeps your chosen view when advancing to the next shot.

The suggested name updates in a label below the optional name input. Placing or dragging points keeps the picture in view and does not update or focus the name input. After saving a shot, input focus is cleared before returning to the picture for the next one.

Planned shot distances show whole metres in setup, play and saved results: 10.4 m shows as 10 m, and 10.5 m shows as 11 m. The original geometry and measurements retain their precision for calibration and SG. Editable measurements and actual finishing distances can still contain decimals.

## Play

Above the overview picture, **Aktuelt slag / Alle slag** switches between the selected position and the complete layout. **Aktuelt slag** is selected by default; use the numbered buttons to preview a different position without changing the round's active shot or clearing entered results. **Skjul færdige slag** optionally removes completed positions from both the picture and number selector. A position remains visible until all its attempts are recorded. Original numbers are preserved, hidden markers cannot be selected, and undo makes an unfinished position visible again. Your filter choices remain in place while recording results and returning to the overview. If every position is hidden after completion, the round can still be finished or the filter switched off to review the completed positions.

1. Starting or resuming a course opens **Slagoversigt**, with all positions numbered on the course picture. Tap a position on the picture or a number below it to see its name, whole-metre distance, starting lie, category and progress, such as **2/5 slag spillet**. Before recording its first result, use **Antal slag − / +** above **Spil slag** to adjust the count for this round; the saved course's defaults remain unchanged. Press **Spil slag** to choose a position or **Fortsæt slag** to continue a partly played position. Remaining positions can be played in any order. Completed positions show their total SG and cannot be selected again.
2. Go to the shown hitting position and play the configured shots towards the target, then register each result in turn. **Slag N af M** shows the attempt being entered. **Slagoversigt** returns to the picture and position selector without losing current input. Choose **Fortsæt slag** to continue that same task. Switching to a different shot with unregistered input requires confirming that this input may be cleared.
3. Enter the actual remaining distance to that target in metres and the ending lie, or select **I hul**. Add any penalty strokes.
4. Press **Gem og næste slag** in the fixed bottom bar. It stays outside the scrolling form, with space reserved above the keyboard. The attempt is saved, outcome input clears, and the counter advances. While more attempts remain at this position, the form stays at your scroll position so you can enter the next result. After its last attempt, the next remaining position's picture opens; use **Slagoversigt** to choose another one at any time. Invalid input or a save failure keeps the current attempt and displays the error beside the button. On the final attempt of the round, **Gem sidste slag** saves it and opens the completed overview. Each attempt starts from the original position, not where the previous ball finished. Individual results are shown in the completed round; the play page keeps the current position, progress and total SG visible.
5. Use **Fortryd seneste** to correct the latest result. The last task actually played reopens with its input restored, even if shots were selected out of order. If current unregistered input would be cleared, confirm or cancel first. Undo can be repeated; later undone results then need to be entered again.
6. **Gem og luk** preserves the round, chosen shot and current input. Open the beta course menu and press **Fortsæt træningsrunde** to resume through the overview. To stop after playing only some shots, use **Afslut og gem** in the round or its active-round card in the menu or saved-course list. It becomes available after at least one result is registered. Confirm to save the recorded results, skip remaining attempts and free the active round so another can be started. Unregistered input is not included as a result. The result page shows the played/planned count and **Afsluttet tidligt**. The saved course retains all positions and its default attempt counts. **Opgiv træningsrunde** still discards the active results. Shared games require all configured attempts and do not offer early finish.
7. After all configured attempts are registered, press **Gem rundens resultat** in the fixed bottom bar or active-round card. Results appear on Start and in History under **Banetræning · Beta**, with each outcome matched to its position and attempt in actual play order. Choosing positions during play preserves the reusable course's original layout and order. Early-finished practice rounds retain the full planned layout, recorded outcomes and early-finish marker through history, export/import and synchronization; unplayed attempts have no result or SG.

SG is expected strokes at the start minus expected strokes at the finish, minus the single shot and penalties. Holed shots have zero expected finish strokes. This uses the application's existing approximate putting, approach and short-game baselines. Long tee-shot/off-the-tee scoring and full hole play are outside this beta flow.

Practice rounds are excluded from normal statistics and Start insights, since single-shot attempts are not comparable to full-hole scores or putting rounds. History contains their individual outcomes, course name, layout and scale. The ordinary round export/import includes these result details, but not local course-image files or the saved-course library. Results remain readable without their original image.

## Save and share a course

Signed-in users can also publish a course to **Banebibliotek**, or create a game with a six-character code for independent play and a shared leaderboard. A game uses fixed positions and attempt counts for every participant. Finish locally and explicitly submit the completed result when connected. See [course library and games](course-library-and-games.md) for the complete flow and server setup.

**Gem bane** persists the reusable setup on this device. Under **Spil bane**, open **☰** on a saved course and choose **Del bane** to share or save a `.golfsgcourse` file through the device's share dialog. It includes the picture, calibration, course and shot names, positions, lies, categories, measured overrides and attempt counts. It excludes player results, active sessions and account information. Anyone you give the file to can import and reuse it; sharing does not grant remote editing access.

On the receiving device, open **Spil bane → Importér bane fra fil** and select the shared file. The course and its picture are saved locally and remain available offline after restarting. Importing the same content again preserves the existing copy, including local edits. A changed shared file creates a separate copy; it does not update existing copies or recorded rounds. Supported pictures are JPEG and PNG, with a 10 MB image limit and 15 MB total file limit. Sharing and importing do not require an account or a running API.

Physical-device acceptance should include saving the shared file, transferring it to another device, importing it, restarting offline, playing and editing the imported course, and importing the same file again without duplicates.

## Verification

Automated coverage checks image aspect ratios, measured overrides, endpoint and whole-shot movement at image boundaries, attempt-count limits, immutable round setup, repeated attempts, partial-position selection and persistence, stale input/result protection, SG outcomes and penalties, duplicate submission, undo in actual play order, failed-save recovery, idempotent archiving, backup recovery, legacy data migration, future-schema preservation and round export/import alignment. Physical-device checks remain necessary for the course-name prompt, shot overview and draft-switch confirmation, offline picture rendering, calibration, tap/drag versus scrolling, large text and lifecycle recovery.
